01 / Connect

One endpoint.
Your existing key.

No local server or package is required. Create a dedicated API key from Settings → API Keys, then supply it as a bearer token. The MCP endpoint must be enabled by the operator with MCP_ENABLED=true.

Connection definition
{
  "mcpServers": {
    "gse-terminal": {
      "type": "http",
      "url": "https://gse.teckdroids.com/mcp",
      "headers": {
        "Authorization": "Bearer ges_live_your_api_key"
      }
    }
  }
}

04 / Smoke test

Verify the wire
before you build.

Use a new, dedicated API key. Do not place a live key in source control, shared shell history, issue trackers, or chat.

Initialize
curl -X POST https://gse.teckdroids.com/mcp \
  -H 'Content-Type: application/json' \
  -H 'Authorization: Bearer ges_live_your_api_key' \
  --data '{
    "jsonrpc": "2.0",
    "id": 1,
    "method": "initialize",
    "params": {
      "protocolVersion": "2025-06-18",
      "clientInfo": {"name": "smoke-test", "version": "1.0"}
    }
  }'
Expected: a JSON-RPC 2.0 response with protocolVersion set to 2025-06-18 and a tools capability. A 401 means the route is live but the credential is absent or invalid.
05 / Security

Keys are credentials.
Treat them that way.

ONE KEY / CLIENT

Create a separate revocable key for each person, device, or automation.

HTTPS ONLY

Never send a bearer key over an unencrypted connection.

LEAST ACCESS

Use a standard account unless Pro-only technical indicators are required.

ROTATE FAST

Revoke immediately if a key appears in logs, screenshots, shell history, or chat.
